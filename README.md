# 🌍 Getting Hands-on Earth Data

## 📖 Overview

This project introduces the fundamentals of **Earth System Science** using the **Galaxy Earth System** platform. Through practical exercises, it explores the major components of the Earth System, available Earth observation datasets, and the tools used to access and analyze environmental data.

The tutorial is designed for beginners interested in Earth science, climate research, and environmental data analysis without requiring prior expertise in the field.

---

## 🎯 Objectives

By completing this tutorial, you will learn how to:

- 🌍 Understand Earth System terminology
- 📡 Explore different sources of Earth observation data
- ☁️ Learn about Earth observations and reanalysis datasets
- 📊 Visualize and analyze environmental data using Galaxy

---

## 🌎 The Earth System

The Earth System is composed of four interconnected components:

- 🌊 Ocean
- 🏞️ Land
- ☁️ Atmosphere
- 🐙 Biodiversity

These components continuously interact with one another, providing a comprehensive understanding of Earth's environment and climate.
